triggers: write, message to, reply to, email to, letter to, wish, birthday, thank you, condolence, apology, invite, draft
---
1. If you don't know who it's for or what it should say, ask one short question.
2. Otherwise write the message straight away, ready to copy. Keep it warm and natural, in the language they'd use with that person.
3. Put the message on its own, without extra commentary inside it, so the Copy button copies just the message.
4. After it, offer one small change in a single line (shorter, more formal, add a greeting).
